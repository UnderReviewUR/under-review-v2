When to pass on a receiving-yards line

Passing is not a cop-out. On receiving yards especially, a forced lean on a soft main or a depth scrap is how weekends get expensive.

Pass when there is no posted main

If you only see integer alt ladders, period props, or a name that looks like special-teams volume, do not invent a number. Wait for a half-point skill main you can actually defend — or skip the market.

Pass when the role is murky

  • Unclear snap share after a roster move or injury shuffle
  • Committee receiving where the line prices a WR1 path the offense may not run
  • Game script one-way: heavy run looks or blowout risk that starves targets

Pass when the edge is “name recognition”

Famous WR, sticky line, no usage argument — that is entertainment, not a take. Under Review will cite the posted board and say pass when the number isn’t there.
